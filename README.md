# E-Commerce Sales Analysis using MySQL

## Project Overview

A small SQL project analyzing customers, products, and orders using MySQL.

## Database Tables

- Customers
- Products
- Orders

## SQL Concepts Used

- SELECT
- DISTINCT
- WHERE
- INNER JOIN
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- Subqueries
- SUM()
- AVG()
- MONTH()
- YEAR()

## Business Questions

1. What are the unique customer cities?
2. Which products have the highest prices?
3. Which orders have a total amount greater than ₹5,000?
4. How much has each customer spent?
5. Which customers spent more than ₹50,000?
6. Which products are priced above the average product price?
7. What are the monthly sales?
8. Who are the top 5 customers by total spending?
